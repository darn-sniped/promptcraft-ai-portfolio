# Prompt Test 01 — Confidence Interval Study Assistant

## Objective

Test whether adding audience, role, structure, constraints, and learning objectives produces a more useful educational response.

## Version 1 — Basic Prompt

Explain confidence intervals to me.

### Observation

The response was generally useful and included definitions, formulas,
examples, and explanations. However, the prompt did not specify the
student's level, learning objectives, desired structure, or assessment
format.

## Version 2 — Structured Prompt

Act as a university Statistics tutor...

[Paste the full Version 2 prompt here]

### Observation

The response followed the requested structure and provided a more
targeted explanation for a 400-level Statistics student. It included
the requested conceptual explanation, mathematical relationships,
Z-versus-t comparison, worked example, common mistakes, and practice
questions.

## What Changed?

Version 2 added:

- Role
- Target audience
- Learning objective
- Output structure
- Mathematical requirements
- Practice questions
- Common-mistake analysis
- Accuracy constraints

## What I Learned

A prompt can be improved by giving an AI clear context, defining the
desired outcome, specifying the output structure, and adding constraints.
Testing different prompt versions makes it possible to evaluate whether
those changes actually improve the result.

## Key Prompt Engineering Principle

Clearer instructions and relevant context can make an AI response more
targeted and useful, but the output should still be reviewed for
accuracy rather than accepted automatically.
