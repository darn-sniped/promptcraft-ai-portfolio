# PromptCraft: AI Prompt Engineering Portfolio

**Created by:** Solomon Perete  
**Focus:** Beginner prompt engineering practice  
**Status:** Learning project

## About
This repository documents my practice with writing, testing, and improving prompts for AI tools. The goal is to make instructions clearer, provide useful context, and evaluate whether an AI response meets the task.

## What’s inside
- `prompts/study-assistant.md` — a prompt for explaining study topics
- `prompts/content-creator.md` — a prompt for drafting social content
- `prompts/research-assistant.md` — a prompt for organizing research
- `lessons-learned.md` — reflections and next steps

## How I practice
1. Define the task and intended audience.
2. Write a first prompt with a clear role, context, and output format.
3. Test it with an AI assistant.
4. Review the response for accuracy, relevance, and clarity.
5. Revise the prompt and document what changed.

## Important note
These are practice prompts, not evidence of professional AI development or guaranteed factual accuracy. Verify important information independently.
